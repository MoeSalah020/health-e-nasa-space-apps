# Contributing to HEALTH-E

Thank you for contributing to **HEALTH-E** (Team MYTHs — NASA Space Apps Cairo 2026).

## Guidelines

1. **Zero-Build Simplicity:** Keep pages self-contained in Vanilla HTML/CSS/JS so the project deploys directly to Vercel or GitHub Pages without a build pipeline.
2. **Case-Sensitive File Paths:** Always match exact file casing in links (e.g., `Monitoring.html`, `Analysis.html`, `Astronaut.glb`) to prevent 404s on Linux-based hosts.
3. **Dual-Audience Parity:** Any new educational or diagnostic content should include both `.kid-copy` (Curious) and `.adult-copy` (Researcher) variants.
4. **Scientific Grounding:** Cite NASA HRP, GeneLab, or NASA-STD-3001 sources when adding new physiological thresholds or countermeasures.
